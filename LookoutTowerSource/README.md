# Lookout tower source

Everything in `Assets/LookoutTower/Models` and `Assets/LookoutTower/Textures` is generated by these scripts
(Python 3.13 + `pip install bpy==5.3.0 numpy scipy pillow`; no Blender install needed).

```bash
cd blender_scripts
python make_textures.py ../out_textures        # PBR texture sets (+ tiles.json)
python make_sky.py ../out_textures/T_SkyNight.png
python build_props.py ../out                    # LookoutTower.fbx + CabProps.fbx (+ Combined.blend)
python build_forest.py ../out                   # Forest.fbx (+ Forest_preview.blend)
```

- Dimensions live at the top of `build_tower.py` (cab size, floor height, stairs, hatch, windows).
- Blender axes map to Unity as (x, y, z) -> (x, z, y): Blender +Y is Unity +Z (north).
- `blend/Combined.blend` is the tower + furniture for editing in Blender; materials there are placeholders,
  `render_preview.py` wires the textures up for Cycles previews.
- After regenerating, copy the FBX/PNG files over the ones in Assets and run Tools > Lookout Tower > Build Everything.
